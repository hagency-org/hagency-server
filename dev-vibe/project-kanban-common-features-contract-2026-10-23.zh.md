# Project 看板常用功能扩展（2026-10-23）

范围：Server 与原生 Client；Cloud 无产品改动。两端同时升级到 project-board-v2，旧固定五列客户端明确显示能力不支持。

- 自定义列：2–12 列，稳定 ID、名称、顺序、完成列标记、可选 WIP 上限。至少保留一个完成列。只能删除没有任务（含已归档任务）的列；先迁移任务，避免隐式数据丢失。配置按看板序列号冲突检测、幂等重放。
- WIP：按列全部未归档任务计算，过滤不影响计数。新增、跨列移动、恢复时在看板事务锁内拒绝超限；列内排序与编辑仍允许。降低上限可形成超限警示，不删除任务。
- 子任务：一层父子关系，同 Project、无自关联/嵌套/环，每个父任务最多 100 个子任务。独立状态、负责人、截止日期；不自动级联完成或归档。父任务详情展示子任务与完成进度，子任务可返回父任务或解除关联。
- 清单：每任务最多 100 项，稳定 ID、160 字名称、勾选状态、顺序；随任务一起保存，使用任务版本号和原始请求重放，冲突保留草稿。
- 升级：独立 v2 SQL 迁移保留 v1 任务和原始幂等回执；生产入口继续使用真实身份、Project 成员校验和同一数据库。
- 验证：真实 PostgreSQL 集成测试、类型/API 合约检查、原生客户端操作列配置/WIP/子任务/清单并核对持久化。静态预览不算交互验证。
